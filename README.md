# Animal Adoption Platform

This project aims to create a web platform that connects shelters, associations, and individuals interested in adopting pets, making the process simple, transparent, and fast.

## Project Structure

- **src/**: Contains the source code for the application.
- **tests/**: Contains the test cases for the application.
- **.github/workflows/**: Contains the CI configuration files.

## Getting Started

To get started with development, clone the repository and install the necessary dependencies.

```bash
git clone <repository-url>
cd <repository-directory>
npm install
```

## Running Tests

To run the tests, use the following command:

```bash
npm test
```

## CI Pipeline

The project uses GitHub Actions for continuous integration, which runs automated tests and linting on each push.
